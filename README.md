# Instrument

A keyboard-based music synthesizer built with Python. Play notes and chords using your computer keyboard with real-time audio synthesis.

## Features

- Play notes and chords via computer keyboard input
- Multiple scale modes: chromatic, major, and minor
- Real-time audio synthesis with NumPy
- Percussion sequencing
- Piano sound samples for realistic playback

## Getting Started

Install dependencies:

```
pip install pygame numpy
```

Run the synthesizer:

```
python synth_player.py
```
